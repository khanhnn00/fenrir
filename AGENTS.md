# AGENTS.md

How to exercise Fenrir end-to-end.

1. `cd core && cargo test` (transfer queue, conflict naming, speed window, cancel and retry through a stand-in ssh, sftp listing scripts; registry incl. machines and the group-column migration, ssh/tmux command building and quoting, ControlMaster args, remote listing/write scripts run through sh, remote event parsing, hook settings wiring, PTY, hook event parsing + cwd->project mapping, file tree).
2. `scripts/build-app.sh` builds `build/Fenrir.app` (ad-hoc signed); `open build/Fenrir.app`. Use `open -n --env FENRIR_HOME=$(mktemp -d) build/Fenrir.app` to keep real data untouched.
3. Sessions survive switching, several per project: `FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=1 build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: `alive=true,true,true`; alpha sessions 1 and 3 are separate shells, session 1 prints the same pid before and after switching.
4. Hooks end to end (runs a real `claude -p`): `FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=claude build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: log shows `state=Working` then `state=Idle unread=1`, and `$FENRIR_HOME/events.ndjson` holds UserPromptSubmit and Stop lines with `fenrir_session`.
4b. Subagents (real claude in a trusted dir, one background subagent that sleeps 45 s): `open -n --stdout $L --stderr $L --env FENRIR_NO_NOTIFY=1 --env FENRIR_CLAUDE_DIR=<trusted dir> --env FENRIR_REPO=$PWD --env FENRIR_HOME=$(mktemp -d) --env FENRIR_SELFTEST=subagent --env FENRIR_SHOTS_DIR=$PWD/build/screens/t020 build/Fenrir.app` (direct exec of the binary never starts the selftest)
   - Pass: log shows `state=Working`, `state=Agents running unread=0 msg=Agents running: 1, sleep probe`, `state=Idle ... msg=Agents finished, idle`, `sawAgentsRunning=true`.
4c. Project cards and shortcuts: `FENRIR_NO_NOTIFY=1 FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=t023 FENRIR_SHOTS_DIR=$PWD/build/screens/t023 open -n --stdout $L --stderr $L --env ... build/Fenrir.app`
   - Pass: every line is `PASS` (⌘T adds a session to the current project, ⌘N opens a landing-zone tab); writes `card-one-session.png`, `card-three-sessions.png`, `card-collapsed.png`.
5. Screenshots: `FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=shots FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir` (seeds synthetic hook events to show every card state; set `FENRIR_NO_NOTIFY=1` to mute macOS notifications).
6. Wire the hooks for real (UserPromptSubmit, Stop, Notification, SubagentStart, SubagentStop): `node scripts/install-hooks.cjs` (backs up `~/.claude/settings.json`, idempotent). Settings (⌘,) shows whether they are wired.
8. Remote machine, no real host: `FENRIR_NO_NOTIFY=1 FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=org FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir` adds a machine project on `fenrir-selftest.invalid` (DNS never resolves).
   - Pass: state stays `Reconnecting` with growing attempts (3 s, 6 s, 9 s), terminal tail shows the ssh error and `[connection lost; reconnecting…]`, Files shows "Cannot list files"; writes `org-card-and-files.png`, `add-project-organization.png`, `settings.png`.
   - Against a real host: add it with Add Machine (the sheet tests ssh first); `ssh -o BatchMode=yes <host> true` must succeed first (key/agent, no prompts). Kill a session's ssh to watch it reconnect and tmux re-attach.
9. Wheel in plain shell and claude TUI (needs a claude-trusted dir): `FENRIR_REPO=<claude-trusted dir> FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=scrollreal build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: `plain after wheel up` yDisp drops to 0, `claude after wheel up` shows `wheelReports>0` and a different screenHash. Shift+wheel scrolls local scrollback instead of forwarding.
10. Session restore: run `FENRIR_CLAUDE_DIR=<trusted dir> FENRIR_REPO=$PWD FENRIR_HOME=$H FENRIR_SELFTEST=restore-seed` via `open -n --stderr log --env ...`, stop it by pid with SIGTERM (no quit handler runs, like a crash), then run `FENRIR_SELFTEST=restore-check` with the same `$H`.
   - Pass: same cards and order, alpha scrollback after `-- restored --`, claude conversation back on screen. State lives in `$FENRIR_HOME/sessions.json` (saved every 5 s and on quit).
11. Terminal height: `FENRIR_CLAUDE_DIR=<trusted dir> FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=fill FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: every `viewH` line shows `leftover=0.0` and `SZ=<rows> <cols>` equal to `rows`; claude's last non-empty alt row is the last row; the cell attrs of the input suggestion show `style=32` (faint).
12. Option+Delete: same env with `FENRIR_SELFTEST=optdel`. Logs key bytes (`1b 7f`), the shell/claude reply bytes, buffer text before/after, and window-server captures `optdel-*-composited.png`.
13. Machines and tabs against a real host (read-only host check first: `ssh -o BatchMode=yes <host> true`, `tmux ls`): `FENRIR_NO_NOTIFY=1 FENRIR_MACHINE_HOST=<host> FENRIR_MACHINE_PATH=/home/<user> FENRIR_REPO=$PWD FENRIR_HOME=$H FENRIR_SELFTEST=machines-seed FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir`, SIGTERM it after `seed: saved`, then rerun with `FENRIR_SELFTEST=machines-check` and the same `$H`.
   - Pass: seed logs the machine list, tabs `Local[session=1] <host>*[session=2]`, the tmux session `fenrir-livecheck-<id>-1` on the host; check logs the same tabs and selection, the earlier terminal content back, then kills only `fenrir-livecheck-*` sessions on the host. Writes `landing-zone.png`, `add-machine.png`, `two-tabs-remote.png`, `two-tabs-local.png`, `restored-tabs.png`.
14. Cursor: `FENRIR_NO_NOTIFY=1 FENRIR_CLAUDE_DIR=<trusted dir> FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=cursor FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: every line is `PASS` (blink toggles >= 4 in 3 s after idle, wheel, click, double click, session switch, typing; steady DECSCUSR shapes never toggle; unfocused is steady); writes `after-cursor-*.png` (the claude suggestion's first letter is drawn light on the cursor block).
15. Layout and Find files: `FENRIR_NO_NOTIFY=1 FENRIR_FIND=sess FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=layout FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: writes `layout-sidebar-open.png`, `layout-sidebar-closed.png`, `layout-files-find.png` (tabs sit in the main area; results ranked, filename first). Icon source `design/fenrir-icon.svg`; `scripts/make-icon.sh` rebuilds `design/Fenrir.icns`.
15b. Find field focus: `FENRIR_NO_NOTIFY=1 FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=focus build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: `PASS field value='zqxw'`, `PASS terminal received nothing`, `PASS Esc returns focus to the terminal` (clicks the field through the window, types, waits out poller re-renders). `layout` also writes `layout-landing.png` (Home).
16. File transfer (SFTP view, real host; uses only a throwaway `fenrir-sftp-test-<ts>` folder it creates and removes under the host's home): `FENRIR_NO_NOTIFY=1 FENRIR_MACHINE_HOST=<host> FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=sftp FENRIR_SHOTS_DIR=$PWD/build/screens build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: drop-handler uploads of a folder and a file are `done`; three same-name uploads wait in `conflict`, then land as `notes (1..3).txt`; the 150 MB upload shows speed, cancels, and leaves nothing on the host; downloads are `done`; `folder sums local==remote: true local==downloaded: true`, `file sha256 original==remote: true original==downloaded: true`; rename and delete work; `scratch folder removed: gone`. Writes `sftp-dual-pane.png`, `sftp-conflict.png`, `sftp-transfer-progress.png`, `sftp-done.png`.
   - Transfers need no sftp server: files stream through `cat`, folders through `tar`, over the ControlMaster ssh. Dragging out to Finder: step 17.
17. Drag out to Finder (real host, throwaway `fenrir-dragout-test-<ts>` folder, removed at the end): `FENRIR_NO_NOTIFY=1 FENRIR_MACHINE_HOST=<host> FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=dragout build/Fenrir.app/Contents/MacOS/Fenrir`
   - Pass: both promises `finished=true error=none`; `folder sums remote==dropped: true`, `file sha256 remote==dropped: true`, `renamed promise ... remote==dropped: true`; both synthetic-event sessions log `began=true`; `scratch folder removed: gone`. A real mouse drag onto Finder cannot be driven headlessly; try it by hand: select rows in the SFTP remote pane or the Files tree of a machine project and drop them on a Finder window (progress appears in the SFTP view's Transfers list).
18. Right panel colours: `FENRIR_NO_NOTIFY=1 FENRIR_REPO=$PWD FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=panel FENRIR_SHOTS_DIR=$PWD/build/screens FENRIR_PANEL_PREFIX=after build/Fenrir.app/Contents/MacOS/Fenrir` writes `<prefix>-view-{short,long,find,context}-{light,dark}.png` (view render) and `<prefix>-{...}.png` (window-server capture; blank when the screen is asleep or locked).
19. Mouse selection and copy (local tmux with `mouse on`, no host needed; kills only its own `-L t021` tmux server): `FENRIR_NO_NOTIFY=1 FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=mouse FENRIR_SHOTS_DIR=$PWD/build/screens/t021 open -n --stdout $L --stderr $L --env ... build/Fenrir.app`
   - Pass: window resizes report `PASS` with local grid == tmux client size; the plain drag shows `selection.active=true`, `bytes sent to remote=0`, text `COPYMARK-a`; copy action fills the pasteboard; both OSC 52 forms (`52;;` and `52;c;`) reach the pasteboard. Option+drag sends the mouse to the app (tmux/TUI).
   - Against a host: `FENRIR_SELFTEST=remote FENRIR_MACHINE_HOST=<host>` runs a throwaway `fenrir-t021probe-*` tmux session: resizes narrow/wide/drag with local grid vs `tmux list-clients`/window size, then the same copy checks; kills its session at the end.
20. Port forwarding (Ports tab, real host, throwaway tmux session `fenrir-t029-<ts>` running an http server on 18929, removed at the end): `FENRIR_NO_NOTIFY=1 FENRIR_MACHINE_HOST=<host> FENRIR_HOME=$(mktemp -d) FENRIR_SELFTEST=t029 FENRIR_SHOTS_DIR=$PWD/build/screens/t029 open -n --stdout $L --stderr $L --env ... build/Fenrir.app`
   - Pass: `PASS detected 18929`, `PASS forward active: true`, `curl through forward: 200`, the second add and a busy local port report `Local port 18929 is in use. Try 18930.`, `curl after stop: 000`. Writes `ports-tab.png`. Each forward is one `ssh -N -L` child with its own connection (no ControlMaster); saved forwards restart on launch.
